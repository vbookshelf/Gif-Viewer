# Gif Viewer
A simple web app to view gifs.

Online demo:<br>
https://gif-viewer.woza.work/

- Browser based html app.
- Runs Locally. Your gifs stay on your device.
- Move slider to resize the gif.

## How to run the app
- Download the project folder.
- Double click the index.html file. The app will open in your browser.
